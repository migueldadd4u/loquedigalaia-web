# Créditos de imágenes reales

Para su uso web se aplicó un recorte centrado a 16:9, redimensionado a 1280 × 720 píxeles, eliminación de metadatos y conversión a AVIF y JPEG. No se añadieron ni eliminaron elementos mediante IA.
