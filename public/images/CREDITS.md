# Créditos de imágenes reales

Todas las fotografías de esta lista son imágenes reales, no generadas con IA. Se descargaron de Wikimedia Commons el 3 de agosto de 2026. Para su uso web se aplicó un recorte a 16:9, redimensionado a 1280 × 720 píxeles, eliminación de metadatos y conversión a AVIF y JPEG. No se añadieron ni eliminaron elementos mediante IA.

La atribución no implica que las personas autoras o las plataformas de origen respalden loquedigalaia. Las licencias indicadas se aplican únicamente a los archivos de imagen asociados, no al resto del proyecto.
